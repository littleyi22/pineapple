# 摩登土產鳳梨酥｜閱讀密室逃脫

這是一款基於網頁的「閱讀理解密室逃脫」遊戲，主題圍繞在臺灣經典糕點——「鳳梨酥」。
透過五個關卡的解謎與選擇題，玩家將探索鳳梨酥的歷史演進、文化混血特色，以及其背後象徵的臺灣風土包容力。

## 遊戲特色
- **五大關卡測驗**：涵蓋現象推論、高階辨析、批判思考、邏輯排序與跨域遷移，全面檢驗閱讀理解能力。
- **隨機題庫**：每個關卡具備 3 道隨機題目，提升重複遊玩價值。
- **最終試煉與證書**：收集完 5 個密碼碎片並回答最終問題後，可獲得專屬的「摩登土產鳳梨酥認證」！
- **精美視覺**：採用溫暖的黃色調與鳳梨綠色，搭配可愛的 Q 版鳳梨動畫。

## 如何遊玩
1. 下載專案資料夾。
2. 在瀏覽器中直接開啟 index.html 即可開始遊戲。
3. 答對關卡問題以獲得密碼碎片，全部通關後解鎖最終密語。

## 使用素材
- 網頁結構：HTML, CSS, JavaScript (無依賴外部框架)
- 圖片：Q版鳳梨圖像 (ssets/img/pineapple.png)
- 音效：背景音樂與過關音效
